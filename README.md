## About The Project
Odin Project (https://www.theodinproject.com) is an amazing research for beginner and intermediate programmers that are looking into advancing their skills in web dev.
It has been featured in many coding courses and recommendations in many platforms, proving its effectiveness in developing programmers that code in best possible practices.
I can confidently say that my code is way cleaner, safer and maintainable, thanks to this web course.
